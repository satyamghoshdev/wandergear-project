WanderGear Backend

Requirements:
- Node.js installed

First time:
1. Open this backend folder in VS Code.
2. Open the terminal in this folder.
3. Run:
   npm install

Start:
   npm start

The API will run at:
http://localhost:5000

Useful endpoints:
GET  /api/health
GET  /api/products
GET  /api/orders
POST /api/orders

Orders are stored locally in:
data/orders.json

This is a learning/demo backend. It does not include real payment processing,
authentication, production security, or a production database.
