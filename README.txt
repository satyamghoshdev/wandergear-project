WanderGear Full-Stack Project

The project is intentionally separated into:

frontend/
    HTML, CSS and browser JavaScript

backend/
    Node.js + Express API and local JSON data

START HERE:
1. Install Node.js if it is not already installed.
2. Open the backend folder in VS Code.
3. Open a terminal there.
4. Run: npm install
5. Run: npm start
6. Open the frontend folder in VS Code.
7. Use Live Server on frontend/index.html.

Do not delete the backend/data/orders.json file; it stores demo orders.
